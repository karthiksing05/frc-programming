## Two paths, one curriculum

The lessons can be done **two ways**, and serious students do both:

- **In your browser.** Stages 0–1B run as embedded interactive widgets — type into a CodeMirror editor, watch a JS simulation respond. Zero install. Works on a Chromebook. The fastest possible feedback loop for early concepts.
- **In VS Code with WPILib.** From Stage 1C onward, lessons graduate to the real toolchain: clone the project repo, edit Java in WPILib's bundled VS Code, run `./gradlew simulateJava`, view results in AdvantageScope. This is what a real season looks like.

By the time you cross from browser to VS Code, you've already written the code you're about to open. The transition is one button press, not a fresh start.

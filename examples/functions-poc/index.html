Methods (a.k.a. Functions)

local_fire_department Tip

A method is a reusable piece of code with a name, some inputs, and an output. Today you'll write one real WPILib utility method — and the file you create is saved to your project so the next lesson can use it.

Why methods exist

In FRC code you do the same little operations all over the place: clamp a value, square a joystick input, convert encoder ticks to meters. If you copy-paste that math into ten different files, then change your mind about how it should work, you have to find and fix all ten copies.

A method lets you write the operation once, give it a name, and call it from anywhere. That's the entire idea.

       if (Math.abs(value) < threshold) return 0.0;

The real-world problem

Real Xbox-controller joysticks are noisy. Even when no one is touching them, the reading drifts between roughly −0.05 and +0.05. If you forward that straight to a motor, the robot twitches and creeps across the field while the driver is just standing there.

The fix is called a deadband: ignore any reading whose magnitude is below some threshold. We'll write it once as MathUtils.applyDeadband(value, threshold) and reuse it everywhere a joystick value enters the robot code.

sticky_note_2 Note · Why static?

Methods marked static belong to the class, not to a specific object. You call them with ClassName.method(...) — no new MathUtils() needed. Utility math is the textbook case for static: it doesn't depend on any state, so there's nothing to put in an instance.

Your task

  1. The starter on the right contains MathUtils.java with a stub method.
  2. Replace the // TODO in the body so the method returns 0.0 when the input is within the deadband, and the original value otherwise.
  3. Press Run (or Ctrl+Enter) — the joystick visualization on the right deploys your method live.
  4. Goal: the green “motor output” bar should sit dead still when you aren't touching the joystick, then respond cleanly once you push past the threshold.
expand_more Hint (try it yourself first!) 
if (Math.abs(value) < threshold) {
    return 0.0;
}
return value;

or, as a one-liner using the ternary operator:

return Math.abs(value) < threshold ? 0.0 : value;

Your saved project

science What gets saved?

When you press Run, your edited MathUtils.java is written to your persistent project filesystem — the same one shown in the right-side “Project Files” panel. The very next lesson (Tank Drive) will import this exact file. If you wreck it now, future lessons break — just like a real robot project.
